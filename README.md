VORTEK TECH AGENCY WEBSITE - README 📋 Overview 9-page corporate website blending futuristic tech with forest aesthetics. Built with React + 21st.dev components, deployed on Vercel with Strapi CMS.

🎯 Tech Stack Frontend: React 18 + TypeScript + Vite

Styling: Tailwind CSS + custom glass morphism

Components: 21st.dev registry (Radix UI based)

Animations: Framer Motion + GSAP

CMS: Strapi (headless) + PostgreSQL

Hosting: Vercel + Cloudflare

🎨 Design System Colors: Forest Green (#228B22), Olive (#556B2F), Neon Green (#39FF14)

Fonts: Orbitron (headings), Roboto (body)

Theme: Glass morphism with leaf-code particle animations

📄 Pages Home - Hero, services, stats, testimonials

About - Timeline, team, values

Services - 5 categories with pricing

Portfolio - Filterable project showcase

Team - Profiles with interactive cards

Blog - Articles with categories

Pricing - Packages & calculators

Testimonials - Client reviews

Contact - Forms & integration
